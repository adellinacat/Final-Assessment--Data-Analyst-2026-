# Final-Assessment--Data-Analyst-2026-
Analysis of the residential real estate market in Los Angeles, California, USA

В работе используются данные личного рабочего архива. Анализируемый датасет состоит из файлов train.csv, test.csv. С целью построения моделей машинного обучения данные синтетически разделены на две части. Используя данные из train.csv, построить модель для предсказания цен на недвижимость (квартиры). С помощью полученной модели предсказать цены для квартир из файла test.csv.

Тренировочный набор содержит 10000 строк информации в 20 колонках, включает строковые, целые, вещественные данные. Тестовый набор содержит 5000 строк, 19 колонок. Целевая переменная: Price, цены указаны в долларах США.
